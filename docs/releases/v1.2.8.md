## v1.2.8

本版修复网页发送端在部分加固或虚拟化 Chromium 环境中无法启动编码器的问题。传输协议未变，与 v1.2.0–v1.2.7 的 descriptor v5 完全兼容。

### WebAssembly SIMD 兼容性修复

- 移除 Rust 发送/接收核心 WASM 的 `+simd128` 全局编译开关，修复 Chrome/V8 报错 `Wasm SIMD unsupported` 导致「编码器初始化失败」。
- MV3 和 Web 仍使用 wasm-bindgen 0.2.125/externref，仅去掉 SIMD 指令依赖；MV2 的旧浏览器兼容路径不变。
- `wasm-pkg-simd/` 和 `npm run wasm:simd` 作为历史构建名保留，其实际产物现为现代标量 WASM，不破坏现有 CI/打包脚本。
- 同步移除网页接收端 FAST ZXing-C++ WASM 的 `-msimd128`；Y 灰度平面快路径、异常处理和 zxing-wasm 回退逻辑保持不变。
- 旧 SIMD 构建在当前 RaptorQ/fast_qr wasm32 热路径上实测无提速，因此本次修复不预期降低发送端编码性能。

### 验证

- 现代 WASM 重建成功，产物 feature 检查不含 `simd` / `relaxed-simd`。
- Web 发送端生产构建通过。
- Web 接收链端到端测试 41 项通过，sessionGuard 23 项通过。
