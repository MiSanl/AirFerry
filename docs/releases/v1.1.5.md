## v1.1.5

> 本版本为**发送端 UI 重构与自适应优化**，不涉及协议与核心库。相对 v1.1.4 的主要更新：发送端界面重新设计、全视口自适应、文件列表默认折叠。下载文件统一带 `sender`（发送端）/ `receiver`（接收端）角色前缀，asset 不设 label。

### 发送端 UI 重构

- **界面重设计**：标题区拆分主标题与副标题（「AirFerry / 无网文件传输 · 屏幕二维码流」）；所有 emoji 图标（📁 ✍ 📦 📄 📝）替换为内联 SVG 矢量图标，继承 currentColor、高清不糊。
- **步骤条优化**：步骤文字标签独立为 `.step-label`；已完成步骤的圆点自动换成对勾；标题与步骤条间距加大。
- **传输参数页**：冗余率 / 亮度等滑块字段重排为「标签 + 当前值」两栏；复选项改为标准勾选布局；新增页面描述行。
- **播放页**：新增「将接收端摄像头对准屏幕，保持画面完整可见」引导；全屏按钮归入独立操作区。
- **错误提示**：错误横幅去掉内联样式，改为语义化 `role="alert"` 与统一样式。

### 全视口自适应

- **智能垂直居中**：内容短时（如空选择页）整体垂直居中，不再贴顶；内容长时（多文件列表）自然滚动，不截断。配合 `100dvh` 适配移动端动态视口。
- **响应式断点**：新增 `≤900px`（平板）/ `≤600px`（手机）/ `≤340px`（极窄屏）三档断点。容器、卡片、QR 画布（`min(600px, 90vw)` 正方形）、拖放区、按钮、表格、弹窗、文件名截断宽度逐档收紧，杜绝横向滚动。
- **极窄屏步骤条**：≤340px（iPhone SE / 折叠屏）自动隐藏步骤文字标签，只显数字圆点，避免 4 个中文标签撑出视口（修复 v1.1.4 在 320px 的横向溢出）。

### 文件列表默认折叠

- **只显数量**：选择页文件列表默认折叠，仅显示「N 项 · 总大小 · 展开」摘要行，不再默认铺开长列表。
- **点击展开**：点击摘要行展开完整列表，每项仍可单独移除；「清空」按钮在折叠 / 展开两种状态都常驻摘要行右侧。

### 无障碍与动效

- **键盘焦点**：主按钮新增 `:focus-visible` 可见焦点环。
- **自定义滑块**：range 滑块统一轨道与拇指样式（Webkit / Firefox）。
- **减弱动效**：尊重系统 `prefers-reduced-motion`，关闭过渡动画。

### 版本

- **1.1.5**（Android versionCode=**10**）；sender/web、Rust 已同步。Windows / APK 接收端二进制与 v1.1.4 一致（本版无协议改动，接收端产物沿用 v1.1.4）。

### 产物
