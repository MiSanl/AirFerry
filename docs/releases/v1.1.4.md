## v1.1.4

> 本版本包含浏览器/网页发送端，以及 Android、Windows 接收端。下载文件沿用历史稳定命名；各端用途、系统要求和架构在下方产物说明中明确标注。

### 扫码修订（重新发布）

- **移除二维码状态**：Android 与 Windows 删除逐二维码活跃/暂停状态行及其时间戳、四宫格映射和定时刷新，避免继续展示不可靠判断。
- **Android 解码回退**：根据 1.1.4 实机反馈，Android 的 `QrDecodePool.kt`、`ZxingDecoder.kt`、`scan_jni.cpp` 精确恢复到 v1.1.3 解码实现；协议安全和文件名导出修复继续保留。
- **Windows 同模式**：Windows 以 C#/C ABI 镜像 Android v1.1.3 的 worker 数、队列容量、4 符号批摄入、全帧/ROI miss 状态机及 TryHarder/TryInvert 选项。

### 体验与性能

- **网页全页拖放**：文件或文件夹可拖到页面任意位置；目录分批递归读取，支持并发拖放、卸载作废和读取中状态。
- **Windows 完整扫码链路**：多 worker 解码 + 串行 Rust 摄入，支持多码 ROI 跟踪、15 FPS 预览与 3 秒实时吞吐窗口。
- **Windows 完整接收流程**：统一 ContentStore 历史、文本/文件/bundle 结果页、原名导出和摄像头原地停止/继续。

### 安全与可靠性

- **WASM session 生命周期**：消除 epoch 失效、替换、卸载和 React StrictMode 下的双重 `free()` 风险。
- **协议输入加固**：补齐 OTI/SBN/ESI/descriptor/Frame 长度校验；C ABI raw pointer API 明确为 unsafe，并修复 assemble 输出参数泄漏边界。
- **资源预算**：对象上限统一为 32 MiB；断点 JSON 输入/输出、符号数量和字节数均有独立预算，降低合法大对象触发 OOM 的风险。
- **ContentStore 故障保护**：损坏索引先备份再停止写入，不再静默清空；Android/Windows 分享保留逻辑文件名、扩展名和 MIME，避免落成 `.bin`。
- **不可信文件隔离**：Windows 历史文件只在应用内预览；外部导出写入 MOTW，不直接 shell 执行接收内容。
- **安全停止**：Windows producer、recovery、worker、native session/camera 严格有序释放；慢驱动超时后后台持有资源，避免并发 free/Dispose。

### 构建与测试

- WASM legacy/SIMD 在隔离 workspace 构建，并用跨进程锁保护发布和消费；web 使用独立现代 WASM 快照。
- Windows 构建仅接受真实 DLL，并由固定 SHA 的 GitHub Actions 在 Windows runner 打包。
- 新增 Android 协议/helper 单测与 Windows C ABI、CRC、预览、导出测试；同步更新协议和构建文档。

### 版本

- **1.1.4**（Android versionCode=**9**）；sender/web、Rust、Windows 和 `windows.yml` 已同步。
