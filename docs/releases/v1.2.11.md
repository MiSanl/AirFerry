## v1.2.11

### 发布流程

- Android 签名 APK 已通过独立 `android-verify` 工作流验证后再进入全量发布。
- `release-all` 仍为唯一的发布工作流，直接在版本 tag 上构建并上传所有资产。
- 修复 Release 汇总 job 引用不存在的 `actions/download-artifact` 提交，确保所有已构建资产可下载并上传到 GitHub Release。
- 未启用的 GitHub Pages 已改为手动触发，不再给正常推送增加失败状态。

### 版本

- Rust / sender / web / desktop / Windows：`1.2.11`
- Android：`versionName 1.2.11`，`versionCode 25`
