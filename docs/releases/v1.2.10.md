## v1.2.10

### CI 修复

- 修复 `release-all` 的浏览器/Web 归档路径，确保所有 zip/xpi/html 进入上传目录。
- CRX 签名改用 Chrome 所需的 PKCS#8 PEM 格式，并在 CI 显式安装 Chrome。
- Android CI 显式安装 command-line tools，使用 `sdkmanager` PATH 入口安装 API、NDK 与 CMake。
- 未启用 GitHub Pages 时，`pages` workflow 不再自动随 `main` 推送运行，避免无意义的部署失败；启用 Pages 后可手动运行或恢复 push 触发器。

### 版本

- Rust / sender / web / desktop / Windows：`1.2.10`
- Android：`versionName 1.2.10`，`versionCode 24`
